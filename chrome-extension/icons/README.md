# Chrome Extension Icons

This directory should contain the following icon files:

- `icon-16.png` - 16x16 pixels (for browser toolbar)
- `icon-48.png` - 48x48 pixels (for extensions page)
- `icon-128.png` - 128x128 pixels (for Web Store)

## Creating Icons

1. Start with a high-resolution APES logo
2. Create square versions at each size
3. Use PNG format with transparency
4. Optimize file size (use tools like TinyPNG)

## Temporary Icons

For development, you can:
1. Use a solid purple square (#9333ea) 
2. Add white "A" text in the center
3. Or use the APES token logo if available

## Icon Requirements

- PNG format required
- Transparent background recommended
- Clear at small sizes
- Follow Chrome's icon guidelines
